# 概率预测的校准方法与赔率数据口径

## 一、评分标准：Brier Score

衡量概率预测准确度的标准尺子，本质是「报出的概率」与「实际结果」的均方误差：

```
Brier = Σ (报出的概率 − 实际结果)²      实际结果：发生=1，未发生=0
```

三项预测（胜/平/负）取值范围 0–2。实测算例：报 `0.51 / 0.24 / 0.25`，实际主胜 →

| 项 | 概率 | 实际 | 差² |
| --- | --- | --- | --- |
| 主胜 | 0.51 | 1 | 0.240 |
| 平 | 0.24 | 0 | 0.058 |
| 客胜 | 0.25 | 0 | 0.063 |
| **合计** | | | **0.360** |

判读标准：

| 值 | 含义 |
| --- | --- |
| 0.00 | 完美（报 100% 且命中） |
| ~0.33 | 很好 |
| **0.67** | 三项各报 33% 的「抛硬币」水平 |
| 2.00 | 完美错误（报 100% 且完全反向） |

优点是**奖惩不对称**：报 90% 错了（罚 1.62）远惨于报 60% 错了（罚 0.32），逼出诚实的概率而非虚张声势。多分类场景可辅以 log-loss（实测 0.920 对 0.921，与 Brier 结论一致）。

## 二、单位口径：必须用 pp（百分点）

「我给 45%、市场 50%」→ 差 **5pp**。不能说「低 5%」，否则会被理解为 45×0.95。

预测工作里天天比较两个概率的差，pp 一刀切掉歧义。典型表述：「竞彩与欧赔分歧 5.1pp」「我的 P(净胜 2+) 偏低 15–20pp」。

## 三、去水（overround 去除）

**不去水之前，所有「市场分歧」都是幻觉。** 竞彩返还率约 87%，亚盘约 97%——水钱厚度差约 10pp。

```
去水概率_i = (1 / 赔率_i) / Σ(1 / 赔率_j)
```

实测算例：竞彩去水主胜 50.7%、欧赔 47.2%，差 3.5pp。直接拿原始赔率互比，会误以为市场存在分歧，其实只是水钱不同。

## 四、欧赔与亚盘的互译（唯一需要动手算的地方）

两者不是同一问题：**欧赔答「谁赢」（连续、精度高），亚盘答「赢多少」（台阶、只能读档位）**。因此不能直接比——亚盘不含平局，欧赔含平局，必须先把口径拉齐。

```
条件主胜% = 主胜% ÷ (主胜% + 客胜%)      # 用于可走水的盘口（平手、平半等）
```

实测算例：欧赔 2.55 / 3.40 / 2.75 → 去水 37.4 / 28.0 / 34.6 → 剔除平局归一 **51.9 / 48.1**；同期亚盘平手 1.90 / 2.00 去水 **51.3 / 48.7**。差 0.6pp → **市场内部自洽**。

### 口径陷阱（最容易犯的错）

**半球盘没有走水**（上盘赢 = 主队获胜），因此对半球盘要用**绝对概率**去比，不能用剔除平局后的条件概率。

实测事故：把条件概率 61.5% 与半球盘的 48% 相比，凭空造出 **13pp 假分歧**。改用绝对概率 47.0% 后，与利记、皇冠、明陞、澳彩、韦德、平博六家（47.4–48.5）差 0.4–1.5pp，市场自洽。

多数人「总觉得欧亚对不上」，根源就在口径没统一。

## 五、市场基准的正确取法

| 规则 | 说明 |
| --- | --- |
| **一律取多机构欧赔中位数** | 不用平均值（易被极端值拉动），不用竞彩 |
| **不拿竞彩当基准** | 竞彩常比中位数短 4–5pp，且系统性偏向国内流量队，会放大自身偏差甚至使其反向 |
| **初盘与临场必须成对记录** | 只记当前赔率等于看不到资金流向；缺初盘就无法判断位移 |
| **数票而非读单家** | ≥5 家同向才算市场信号；单家调价多为该机构自身风控 |
| **区分初盘/临场概率** | 曾把初盘 44% 当作基线，导致方向判断反向 |

## 六、大小球作为 λ 的硬约束

大小球盘口可以反推**总进球期望 λ**，把泊松模型的两个自由度压到一个（只剩「两队实力差」）。

实测换算：

- 大球去水概率 50% → 总 λ ≈ 2.7
- 3.5 球盘去水大球 48.9%（即 P(总进球 ≥4) = 48.9%）→ 总 λ ≈ 3.62
- 参考表：λ 从 2.0 到 3.2 对应 P(总进球 ≥3) 从 32.3% 到 62.0%

**用途**：先锁 λ 总量，再扫「λ 差」做敏感性。实测一次：自建 λ 合计 2.95 vs 市场隐含 3.62，差 0.67 球/场；把总量对齐后，主胜概率在 λ 差 0.30–0.90 区间跨度 12.5pp，市场值完整落入区间 → **自身摇摆 > 与市场分歧 → 判噪声**。

## 七、校准分析的分层维度

单看总体均值会掩盖问题。有效分层：

| 维度 | 实测发现 |
| --- | --- |
| 批次（深度 vs 批量） | 逐场深挖 0.522 优于市场 0.695；批量快测 0.547 劣于市场 0.514 |
| 置信度标注 | medium 组 0.708 反而差于 low 组 0.501（**反校准**） |
| 联赛 | 强弱悬殊联赛（西甲）0.432 与市场持平；冷门密集联赛（德甲）双方均 0.73+ |
| 盘口类型 | 让球盘方向命中 2/7，全部押同一侧 → 系统性偏差 |
| 第三方基准 | Opta 仅 4 场样本、均值 0.629，样本不足不能作结论 |

**样本量纪律**：4 场不足以评价一个模型；20 场可以看批次差异但不够看分层；分层结论至少需要数十场。任何基于 3–5 场的「某方更准」都是噪声。

## 八、可证伪预言机制

每次预测必须同时写下：失败概率 + 可证伪条件（「若出现 X，则判为某类系统性偏差发作」）。

作用：赛后可归因。实测中，唯一精确应验的预言正是这种形式；而没有写预言的方向判断，事后只能得到「错了」而无从判断是运气还是偏差。

## 九、可复用的自检顺序

1. 各自去水（否则一切比较无效）
2. 初盘 → 当前的位移方向与幅度
3. 数票（≥5 家同向）
4. 口径对齐后互译（可走水盘用条件概率，半球盘用绝对概率）
5. 大小球反推 λ 总量并锁定
6. 只扫剩余自由度，看市场值是否落在自身敏感性区间内
7. 落在区间内 → 噪声，停手；超出区间 → 再查是否有对应的**已确认新闻**，找不到可验证原因的一律按「我错了」处理
