# 概率预测的校准方法与赔率数据口径

## 一、评分标准：Brier Score

衡量概率预测准确度的标准尺子，本质是「报出的概率」与「实际结果」的均方误差：

```
Brier = Σ (报出的概率 − 实际结果)²      实际结果：发生=1，未发生=0
```

三项预测（胜/平/负）取值范围 0–2。实测算例：报 `0.51 / 0.24 / 0.25`，实际主胜 →

| 项 | 概率 | 实际 | 差² |
| --- | --- | --- | --- |
| 主胜 | 0.51 | 1 | 0.240 |
| 平 | 0.24 | 0 | 0.058 |
| 客胜 | 0.25 | 0 | 0.063 |
| **合计** | | | **0.360** |

判读标准：

| 值 | 含义 |
| --- | --- |
| 0.00 | 完美（报 100% 且命中） |
| ~0.33 | 很好 |
| **0.67** | 三项各报 33% 的「抛硬币」水平 |
| 2.00 | 完美错误（报 100% 且完全反向） |

优点是**奖惩不对称**：报 90% 错了（罚 1.62）远惨于报 60% 错了（罚 0.32），逼出诚实的概率而非虚张声势。多分类场景可辅以 log-loss（实测 0.920 对 0.921，与 Brier 结论一致）。

## 二、单位口径：必须用 pp（百分点）

「我给 45%、市场 50%」→ 差 **5pp**。不能说「低 5%」，否则会被理解为 45×0.95。

预测工作里天天比较两个概率的差，pp 一刀切掉歧义。典型表述：「竞彩与欧赔分歧 5.1pp」「我的 P(净胜 2+) 偏低 15–20pp」。

## 三、去水（overround 去除）

**不去水之前，所有「市场分歧」都是幻觉。** 竞彩返还率约 87%，亚盘约 97%——水钱厚度差约 10pp。

```
去水概率_i = (1 / 赔率_i) / Σ(1 / 赔率_j)
```

实测算例：竞彩去水主胜 50.7%、欧赔 47.2%，差 3.5pp。直接拿原始赔率互比，会误以为市场存在分歧，其实只是水钱不同。

去水的第二个用途是**算保本门槛**：返还率 87% 的市场，三个赛果实际需要超越的最低 edge 并不相同（实测萨索洛场为 4.9 / 3.9 / 6.1pp）。任何固定 3pp 阈值的价值判定都会系统性制造假信号。

## 四、欧赔与亚盘的互译（唯一需要动手算的地方）

两者不是同一问题：**欧赔答「谁赢」（连续、精度高），亚盘答「赢多少」（台阶、只能读档位）**。因此不能直接比——亚盘不含平局，欧赔含平局，必须先把口径拉齐。

```
条件主胜% = 主胜% ÷ (主胜% + 客胜%)      # 用于可走水的盘口（平手、平半等）
```

实测算例：欧赔 2.55 / 3.40 / 2.75 → 去水 37.4 / 28.0 / 34.6 → 剔除平局归一 **51.9 / 48.1**；同期亚盘平手 1.90 / 2.00 去水 **51.3 / 48.7**。差 0.6pp → **市场内部自洽**。

### 口径陷阱（最容易犯的错）

**半球盘没有走水**（上盘赢 = 主队获胜），因此对半球盘要用**绝对概率**去比，不能用剔除平局后的条件概率。

实测事故：把条件概率 61.5% 与半球盘的 48% 相比，凭空造出 **13pp 假分歧**。改用绝对概率 47.0% 后，与利记、皇冠、明陞、澳彩、韦德、平博六家（47.4–48.5）差 0.4–1.5pp，市场自洽。

多数人「总觉得欧亚对不上」，根源就在口径没统一。

## 五、市场基准的取法：盘口与水位必须成对记录

| 规则 | 说明 |
| --- | --- |
| **一律取多机构欧赔中位数** | 不用平均值（易被极端值拉动），不用竞彩 |
| **不拿竞彩当基准** | 竞彩常比中位数短 4–5pp，且系统性偏向国内流量队，会放大自身偏差甚至使其反向 |
| **初盘与临场必须成对记录** | 只记当前赔率等于看不到资金流向；缺初盘就无法判断位移 |
| **数票而非读单家** | ≥5 家同向才算市场信号；单家调价多为该机构自身风控 |
| **区分初盘/临场概率** | 曾把初盘 44% 当作基线，导致方向判断反向 |
| **盘口与水位是两个独立维度** | 「盘口不动」不等于「没有信号」；必须同时记初盘/当前的**盘口**与**水位** |

最后一条是本次新增。四场实测中，纽卡与拉科两场的全部方向信息都在水位里：盘口从半球原地不动，但上盘水位由 0.88 抬到 0.97–1.06。只记录盘口会读到「无变化」，改成双维度后立刻读出「资金离开上盘」。

**可操作阈值**：水位同向移动 ≥ 0.05 视为有效信号；单家移动不计，需 ≥5 家同向。

## 六、大小球与 λ 总量：从「硬约束」降级为「参考约束」

> 本节为 2026-11-02 的重大修订，推翻了 2026-11-01 版确立的硬约束规则。

大小球盘口可以反推**总进球期望 λ**，这一换算本身是可靠的：

- 大球去水概率 50% → 总 λ ≈ 2.7
- 3.5 球盘去水大球 48.9%（即 P(总进球 ≥4) = 48.9%）→ 总 λ ≈ 3.62
- 参考表：λ 从 2.0 到 3.2 对应 P(总进球 ≥3) 从 32.3% 到 62.0%

**被推翻的是「拿它锁死自建 λ」这一步。**

### 证伪实证

11-01 曾把该换算立为硬约束：先用大小球反推 λ 总量锁死，再只扫「两队实力差」一个自由度。次日弗罗西诺内 vs 都灵一场首次检验即失败：

| 版本 | λ 总量 | 发布主胜 | Brier |
| --- | --- | --- | --- |
| 原版（自建 λ） | 2.95 | 55.9% | **0.293** |
| 修正版（锚定市场隐含 λ） | 3.62 | 52.5% | 0.340 |
| 竞彩 | — | — | 0.352 |
| 市场欧赔 | — | — | 0.424 |

实际总进球只有 2 个，自建的 2.95 更接近真相。强行锚定到市场的 3.62 反而使 Brier 恶化 0.047。

**根因**：硬约束的前提是「市场的大小球定价一定比我准」。该前提不成立——市场的 O/U 同样会错，尤其在「强队残阵」与「升班马爆发期」两类场景下会系统性偏高（已累计 2 例，待第 3 例确认）。

### 修订后的流程

1. 先用大小球反推 λ 总量，**只作为参考区间**记录在案；
2. 自建 λ 落在参考区间内 → 直接采用自建值；
3. 自建 λ 显著偏离（> 0.5 球）→ **不自动锚定**，而是把该偏离本身当成待解释的信号：要么找到可验证的阵容/战术原因，要么承认自己在猜；
4. 无论哪种，都不得把市场隐含 λ 当作既定事实写进模型。

**通用教训**：把「另一个信息源」写成硬约束，等价于把该源的误差吸收进自己的模型，同时丧失事后归因能力。约束只能来自逻辑上不可违反的关系（如三项概率和为 1），不能来自另一个预测者的判断。

## 七、噪声判据：欧亚自洽 + 敏感性检验

判定「我发现市场错价」之前必须连续通过三道检验，任何一道不过即判噪声。

### 第一道：欧亚互译自洽性

把欧赔按各家共识盘口口径换算后与亚盘水位比较，差值 < 2pp 视为市场内部自洽。市场自己没错价，就不太可能存在可利用的跨市场裂缝。

实测：11-03 凌晨四场互译差 1.0 / 1.8 / 0.9 / 1.1 pp，全部自洽 → 四场全部否掉。

### 第二道：分歧是否大于自身不确定性

固定 λ 总量、只扫描实力差 ±0.25 球，观察主胜概率的摆动幅度（即「自身摇摆」）：

| 场次 | 我的分歧 | 自身摆动 | 判定 |
| --- | --- | --- | --- |
| 萨索洛 vs 佛罗伦萨 | 1.9pp | 10.8–12.3pp | 噪声 |
| 亚特兰大 vs 帕尔马 | 6.5pp | 10.8–12.3pp | 噪声 |
| 纽卡斯尔 vs 埃弗顿 | 7.0pp | 10.8–12.3pp | 噪声 |
| 拉科鲁尼亚 vs 奥萨苏纳 | 2.5pp | 10.8–12.3pp | 噪声 |

**判据**：分歧 < 自身摆动 → 该「分歧」在统计上不可区分于参数选择，不能叫 edge。

这条检验的价值在于把「我觉得市场错了」翻译成一个可计算的量。固定 pp 阈值（如「差 3pp 就算机会」）没有意义，因为不同场次的模型敏感度可差 3–4 倍。

### 第三道：方向是否与已知偏差同向

若分歧方向与自己已确认的系统性偏差同向（如「主胜系统性低于市场」），优先判定为偏差复发，而非发现裂缝。细则见《LLM 概率预测的能力边界与偏差清单》。

## 八、比分赔率结构：可用的「第四条线」

正确比分区（比分盘）常被当作噪声，实测它提供两条独立信息，且都不依赖具体比分命中：

1. **形态信息**：最低四档比分若全部落在 1 球差（1-0 / 0-1 / 1-1 / 2-1），读作「胶着的一球局」；若最低档出现 2-0、3-1 等，读作「可能拉开」。
2. **独立性校验**：比分盘隐含的胜平负聚合值应与欧赔接近，若差 > 3pp，说明有一方定价异常，值得单独查。

实测两次应验：利物浦 vs 阿森纳赛前「1-1 独占最低 + 最低四档全是 1 球差」→ 实际 0-1，精准落在第四档。

**边界**：该线只用于判断「赢几个」的形态，**不能用于判断「谁赢」**。把它当方向依据会立刻退化成抛硬币。

## 九、校准分析的分层维度

单看总体均值会掩盖问题。有效分层：

| 维度 | 实测发现 |
| --- | --- |
| 批次（深度 vs 批量） | 逐场深挖 0.522 优于市场 0.695；批量快测 0.547 劣于市场 0.514 |
| 置信度标注 | medium 组 0.708 反而差于 low 组 0.501（**反校准**） |
| 联赛 | 强弱悬殊联赛（西甲）0.432 与市场持平；冷门密集联赛（德甲）双方均 0.73+ |
| 盘口类型 | 让球盘方向命中 2/7，全部押同一侧 → 系统性偏差 |
| 第三方基准 | Opta 仅 4 场样本、均值 0.629，样本不足不能作结论 |

**样本量纪律**：4 场不足以评价一个模型；20 场可以看批次差异但不够看分层；分层结论至少需要数十场。任何基于 3–5 场的「某方更准」都是噪声。

## 十、方向输出的停权机制与成本台账

这是一个可复用的治理设计，不限于足球预测：**当某类输出被证明长期负价值时，不是继续微调，而是先停掉输出，再用可量化的解锁条件恢复。**

### 触发条件

- 给方向的 4 场全错；
- 判噪声（不给方向）的 3 场热门全部打出。

两类证据方向一致 → 方向输出停权。

### 解锁条件

连续 20 场校准 Brier ≤ 市场基准。用「连续性 + 相对基准」而非绝对分数，避免用一次好运解锁。

### 成本台账

停权不是免费午餐：不给方向可能错过真实机会。因此停权期间必须记账：

| 场景 | 记账方式 |
| --- | --- |
| 停权后结果与「若给方向会给出的方向」一致 | 记「本可以给对」，负成本 |
| 停权后结果与「若给方向会给出的方向」相反 | 记「幸好没给」，正成本 |
| 只是跟随市场倾斜而正确 | 不计功过（跟随不算本事） |

实测两笔相互抵消，净成本 0；尤文场则记为「避免了一次错误下注」，为正收益。

**价值**：台账把「谨慎」从一种态度变成可被审计的成本项。没有台账的停权，三个月后无法回答「当初停得对不对」。

## 十一、可证伪预言机制

每次预测必须同时写下：失败概率 + 可证伪条件（「若出现 X，则判为某类系统性偏差发作」）。

作用：赛后可归因。实测中，唯一精确应验的预言正是这种形式；而没有写预言的方向判断，事后只能得到「错了」而无从判断是运气还是偏差。

**写法要求**：预言必须指向可观测的结果形态，不能是「如果市场错了就说明我对」。有效示例：「若弗罗西诺内赢且净胜 2+，则判定 λ 收缩过度」——实际 2-0，预言精确应验，并直接推翻了硬约束规则。

## 十二、可复用的自检顺序

1. 各自去水（否则一切比较无效）
2. 初盘 → 当前的**盘口位移**与**水位位移**（两个维度都要）
3. 数票（≥5 家同向）
4. 口径对齐后互译（可走水盘用条件概率，半球盘用绝对概率）
5. 计算欧亚互译差，< 2pp → 市场自洽，跳到第 8 步
6. 大小球反推 λ 总量，作为**参考区间**（不锁定）
7. 锁 λ 总量、扫实力差 ±0.25，得自身摆动幅度；分歧 < 摆动 → 噪声
8. 落在区间内 → 停手，只给概率；超出区间 → 再查是否有对应的**已确认新闻**，找不到可验证原因的一律按「我错了」处理

## 十三、敏感性扫描基准 bug 与回填数据源纪律（2026-11-03 新增）

### 敏感性扫描的重大 bug：丢基准 = 判定全部作废

第七节的「自身摆动」检验依赖敏感性扫描。11-03 批量建模 8 场时发现**扫描代码丢掉了基准实力差——围绕 0 扫描，而不是围绕真实估计的实力差扫描**。后果：所有基于该扫描的「噪声/裂缝」判定不可信，此前输出的判定必须作废重跑。

修复重跑后判定反转：8 场中 **3 个裂缝场**（黄潜 vs 巴黎、曼联 vs 罗马、费耶诺德 vs 国米）、5 个噪声——与修复前的分布显著不同。

**规则**：敏感性扫描必须围绕**实际估计值**扫（扫描中心 = 模型自己的点估计），围绕 0 扫描得到的摆动幅度是错位的，用它对比「与市场的分歧」会产生系统性误判。任何「判定类」输出上线前，先人工核一遍扫描中心。

### 回填数据源的两个坑

1. **football-data CSV 有约 1 天延迟**：凌晨场次在次日清晨仍未收录（当时只更新到前一日）。**规则**：回填自动化遇到「未收录」先判断是延迟还是队名不匹配；延迟场景改用 WebSearch 交叉验证，每场 ≥3 个独立来源，不要空转重试 CSV。
2. **同名比赛混入搜索结果**：搜索「纽卡斯尔 vs 埃弗顿」时混入上赛季末轮旧比赛（2026-05-25，同样 0-1、进球者 Alcaraz 65'）；当日真实比赛是 49' Thierno Barry 进球（VAR 确认）。**规则**：赛果甄别必须核对「日期 + 进球人 + 轮次/积分榜」三要素，比分相同 + 队名相同的历史比赛是最危险的污染源。

### 信源分级的执行案例

Codex 报出巴黎中轴四主力缺阵（Marquinhos、Nuno Mendes、Kvaratskhelia、Dembélé），但信源是预测型站点（C 级推断，按规则不采信）。经 FotMob + 巴黎人报核实为真（克瓦拉茨赫利亚 ACL 断裂赛季报销、登贝莱三周、马尔基尼奥斯与努诺·门德斯肌肉伤、四人未随队）后才写入模型。

**规则**：外部模型（包括付费 LLM）给出的事实同样要过信源分级；它转述的「预测型站点内容」等级不因转述者可靠而升级。

### 三源批量流程与竞彩核销口径

- **三源流程（我 + deepseek + codex）首次批量跑通 9 场**：deepseek 服务忙（503）时降档 `deepseek-flash` 重试可行；费耶诺德不在数据集内时手写 prompt 复用同一模板（要求外部模型自行联网查证）。
- **裂缝强度的量化口径**：三方（方法互不相同）同向偏离市场的 pp 数为最强裂缝信号（费耶诺德场：我 +20 / deepseek +12 / codex +7pp，另加劳塔罗伤缺、费耶诺德场均 3.0 火力两个新事实）。

## 十五、杯赛建模：战意与轮换的量化位置（2026-11-05 新增）

### 前提：杯赛误差主要来自阵容，不来自技战术

同一支球队在联赛与杯赛的 λ 可以相差 0.8 球以上，差异几乎全部由轮换解释。因此杯赛流程的第一顺位不是调 λ，而是先判「这场他们上不上人、能不能上人」。**把杯赛当联赛建模，误差会集中在最不该错的地方。**

### 三个必查因子

1. **赛程位置与保级/争冠压力**：联赛深陷降级区（如英超 9 轮 2 胜）的球队，杯赛大概率小幅轮换、点到为止。判据不是「是否重视」，而是「下一场联赛的权重」——重视与否是表态，权重才是约束。
2. **赛季目标窗口**：队史首次欧战、或该杯赛已成赛季唯一亮点时，战意不打折；反之若联赛已无望且杯赛已出局，则不可假设战意。
3. **可用人数（区别于轮换意愿）**：伤病名单长度决定下限。霍芬海姆 10 人伤停、正印中卫只剩 2 人——这不是「是否轮换」的问题，是「无人可换」。**战意高 + 阵容残 = 高战意低产能**，两个因子必须分开建模，不能相互抵消成「中性」。

给出结论时的写法应当是「战意：满；产能：残阵折扣」，而不是笼统的「客队战意强」。

### 停赛的跨赛事边界（高频错源）

**联赛红牌停赛不适用于欧战**（实例：马特塔英超停赛、欧联可上）。反向亦成立：欧战累积黄牌停赛不影响联赛。

任何「某球员停赛」的事实进入模型前，必须先确认停赛所属赛事；未确认赛事属性的停赛，按「不确定」处理而非「缺席」处理——**待确认的代价低于误判的代价**。

### 盘口信号的读法

以水晶宫 vs 霍芬海姆为例：大小球 3.0 → 3.25，个别机构 2.5 直跳 3.5；模型 P(总进球≥3)=56.6%。

- **盘口升级与模型同向 → 可增加信心**。总进球盘的资金流比胜负盘更少被叙事污染，同向的信息价值更高；
- 亚盘主让 0.5 水位微降只代表资金小幅偏主，**不足以支撑「主队大胜」这类分差结论**；
- 两者要分开记账：同向加信心，水位微调不加。

### 战术模拟与概率模型的分工

战术板模拟（首发 XI 预测 + 阵型 + 关键对位 + 剧本推演 + 模拟比分）确立为**独立产品线**：

- 不进发布值、不进 Brier 统计、按需触发、不默认每场都跑；
- 赛后单独核销「剧本兑现度」（胜负手是否真的决定了比赛），这是概率模型无法提供的验证维度；
- 与模型的关系是**概率视角 vs 对局视角**：模型答「各结果多大概率」，模拟答「这场会怎么演」。两者可交叉验证，**不可混算**——混算会让赛后无法归因到底是概率错还是剧本错。

## 十六、EV 口径与临场盘口复核（2026-11-06 新增）

### EV：把「对不对」换算成「值不值」

前面各节解决的是「我的概率是否可信」，这一节解决另一个问题：**可信的概率不等于值得下注**。

```
EV = 模型概率 × 赔率
竞彩去水概率_i = (1 / 赔率_i) / Σ(1 / 赔率_j)
```

| EV | 判读 | 动作 |
| --- | --- | --- |
| ≥ 1.05 | 有价值 | 可下；同时比对欧洲同向是否更高价 |
| 0.95–1.05 | 保本边缘 | 只做小仓试水；价值在别处（更高赔率的市场） |
| < 0.95 | 无 edge | 归为「方向对但不便宜」，不因方向正确而下注 |

实测两注（11-07 凌晨场，用户自选）：

| 注 | 模型概率 | 竞彩去水 | EV | 结论 |
| --- | --- | --- | --- | --- |
| 威尼斯 负 @2.62 | 37% | 33.5% | 0.97 | 保本边缘；真正的价值在欧洲 3.0+ 的价 |
| 塞维利亚 胜 @1.68 | 48% | 52.2% | 0.81 | 无 edge；市场比我更信主队，买 1.68 等于接盘市场定价 |

**关键区分**：模型概率高于去水概率（37% vs 33.5%）只说明「我比市场乐观」，不说明「这注能赚钱」。前者是**看法分歧**，后者才是 **edge**；判断一注能不能下，必须两关都过。反过来，「EV<1 但方向可能对」是常态——这类注的正确处理是不下，而不是减小仓位装作下了。

### 临场盘口复核：把赔率移动当独立信息源

赛前 3–4 小时再抓一次盘口，只读三件事（初盘 → 当前）：

| 维度 | 威尼斯场 | 塞维利亚场 |
| --- | --- | --- |
| 竞彩主胜 | 2.16 → 2.25（升） | 1.80 → 1.68（降） |
| 欧赔主胜 | 2.1 → 2.3+（多家同步升） | 2.05 → 1.88（多家同步降） |
| 亚盘 | 主让 0.25、升水 | 主让 0.25 → 0.5（升盘） |
| 读法 | 资金撤离主队，强化客胜方向 | 资金一致走向主队，强化主胜 |

三条执行规则：

1. **多市场同向才算信号**。竞彩单家从 2.16 变 2.25 不足以作为依据；须欧赔、亚盘、竞彩三方同向（延续第五节「数票」纪律）。
2. **盘口与模型同向 → 维持方向，但不自动提信心**。盘口是别人的结论，同向不构成新证据；只有新增**事实**（首发、伤停）才允许提信心。
3. **盘口与模型反向 → 先查事实层，不先翻方向**。反向信号优先解释为「我漏了伤停/首发」，查完仍无解再按「信市场」处理（对应第七节第三道检验）。

### 信号冲突：只调信心，不翻方向

塞维利亚场同时存在两类强信号：

- 强多头：亚盘 0.25→0.5、欧赔 2.05→1.88、竞彩 1.80→1.68，三方一致；
- 强反向硬数据：阿拉维斯近 4 次联赛做客皮斯胡安不败。

处理：**方向维持主胜，信心下调一档，两条反向事实原样写进备注**。

理由：方向由概率底座决定，信心由证据冲突程度决定。两者混算会导致「每遇到一条反向数据就翻方向」，最终结果等于跟随最后读到的信息——这是比模型偏差更难察觉的流程性错误。

### 事实层「存疑」不得进入参数

罗梅罗伤情多家口径不一：部分预测首发无他（斯塔辛单箭头），另一部分称已回归合练。处置：**存疑只进风险栏，不做 λ 折减**。

- 按「确定缺阵」折减 → 把不确定性当确定性；
- 按「确定出场」不设防 → 同样错。
- 判定标准回到信源分级：只有 A 级（官方确认首发）才能写入模型，其余按原 λ 建模并标注风险。

### 两项数据完整性检查（本次新增）

1. **比分字段为空时，「未命中」是假信号。** 11-06 回填水晶宫场，`settle` 报「我的比分命中 ✗ 未中（我的前四：空）」，而赛前模拟比分实为 1-1、实际也是 1-1。根因：赛前模拟比分只写进对话与 memory，**没有写入该场的比分字段**，核销工具无从读取。规则：核销前先确认该场 `scores` 非空；为空时标「记录缺失」，不得计为「未中」——否则会把一次正确的比分判断记成失败，污染后续的比分能力评估。
2. **人工转录的概率必须回库校验。** 当日 memory 手写的 deepseek 概率为 32/27/38，而库内实为 38/27/35；由 Brier 0.800 反解只与后者自洽。手写数字一旦进入偏差台账，后续所有基于它的推理都会继承这个错误。

## 十七、七维加权建模法首发（2026-11-07 新增）

### 方法缘起与总体结构

应用户提出的「多方向分别给胜率、再定权重合成」思路，对 11-08 的 9 场批量建模改用**七维加权法**：每个维度独立产出一组 1X2 概率，再按基准权重合成。维度、权重与算法如下：

| 维度 | 基准权重 | 算法 |
| --- | --- | --- |
| 实力 | 0.27 | 双口径 λ（进球×xG 乘除）+ 向联赛基准收缩 30% |
| 主场 | 0.10 | 主队主场进攻 vs 客队客场防守的原始拆分 |
| 状态伤停 | 0.19 | 近 5 轮相对**自身**赛季均值的偏离 + 关键球员缺阵扣 λ |
| 排名 | 0.07 | 积分率之差做指数修正（封顶 ±1.2，防爆炸） |
| 赔率 | 0.24 | 欧洲平均去水 + 初盘→当前移动方向加 25% 惯性 |
| 交锋 | 0.07 | 战绩向联赛基准收缩 k=n/(n+8)，5 场旧账不能压过现状 |
| 裁判 | 0.06 | 仅英超场次有明确风格数据时启用（如 Brooks 鼓励对抗、Jones 点球保守），其余归零 |

设计意图与既有规则的对应关系：状态维度用「相对自身均值」而非「相对联赛均值」，修正了此前把拜仁客场实力压缩的同类错误；交锋维度收缩系数 k=n/(n+8) 是「交锋史权重上限」的连续化版本；裁判维度仅在数据可核验时启用，其余归零而非猜测。

### 首跑暴露的三个结构性问题与修正

| 问题 | 实测表现 | 修正 |
| --- | --- | --- |
| 无交锋数据的场次用联赛基准填充 | 阿森纳 vs 赫尔城被算成主胜 65% | 交锋缺失时不填充，直接让该维度降权 |
| 状态维度以联赛均值为基准 | 拜仁客场实力被系统性压缩 | 改为相对自身赛季均值的偏离 |
| 排名维度用积分比 | 对强弱差压缩过度 | 积分率之差做指数修正并封顶 ±1.2 |

修正后的统一原则：**所有维度都以实力模型的 λ 为基准做修正，而不是各自向联赛均值回归**——联赛均值是「平均比赛」的属性，不是「这场比赛」的属性。

### λ 总 +0.4 校准的首次批量应用

11-07 立规（λ 总连续三轮低估约 0.68 球，见《偏差清单》第十三节）后，本批对让球与比分统一执行 λ 总 +0.4 修正。诚实备注保留了两条：让球 8 注中 6 注仍为让负（结构性偏向下盘），让球只做参考不做主推；都灵场模型与市场反向（42.6 vs 52），按「先怀疑自己」取市场侧、信心压低。

### 分歧保留的准入条件（与叙事型硬规则配套）

- **利兹 vs 热刺（唯一保留分歧的场，标 ★）**：我给主胜 44.4 vs 市场 34.7，Opta 41.7 与我同侧。论据全部为硬数据口径——热刺 5 名攻击手同时缺阵、利兹主场跨季 8 场不败、裁判 Brooks 尺度开放利好高强度逼抢。**分歧来自硬数据而非叙事，允许保留。**
- **罗马 vs 萨索洛（校准基准点）**：模型与市场差仅 0.1–0.3pp，无信息增量，但作为 λ 系统性偏移的对照组保留——赛后可直接检验发布值有无偏移。

### 重点球员/关键缺阵的固定化

延续 11-05 确立的「决策信息 ⊇ 建模信息」，本批每场单列重点球员与关键缺阵（如勒温占利兹全队进球 41%、拉伊蒙多 8 球伤缺为客胜判断的最大反向风险）。此类信息同时承担两个职能：建模扣 λ 的依据 + 推荐话语的反向风险披露。

### 逐维核销计划（方法论的自我迭代机制）

赛后回填时统计**七个维度各自命中几场**，用各维度的独立命中率决定下一轮砍谁的权重（裁判维度因数据覆盖最窄，最可能被砍）。这一步把「方法好不好」从整体 Brier 拆到维度层面——整体打平时，只有逐维数据能指出改进方向。
