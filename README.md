## 收录标准

1. **可复用性**：内容能被后续项目直接引用，而非一次性记录。
2. **可溯源**：注明来源链接或原始文档，便于核验。
3. **时效性**：标注整理日期；模型相关结论须写明版本号。

## 文档约定

每份文档开头统一标注：

```markdown
> 主题：
> 来源：
> 整理日期：
> 适用版本：
```

- 结论与事实分开表述，不确定内容标注「待验证」。
- 单个主题内容过多时拆分为独立文档，避免单篇过长影响检索精度。
